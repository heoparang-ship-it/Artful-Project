## 0. 문서 지위와 사용법

### 0.1 목적

1) 세 발주 문서에 잔존하는 `[대괄호]` 표기 항목을 전수 수집하여, 계약 체결 전 확정 절차의 단일 관리표로 삼는다.
2) 각 항목에 **권고안**과 **미확정 시 판정 불능이 되는 조항**을 병기하여, 확정 지연이 어떤 검수·정산 절차를 정지시키는지 사전에 드러낸다.
3) 확정값 열은 공란이다. 확정 즉시 본 표의 확정값 열과 원 문서의 `[대괄호]`를 **동시에** 치환하고, 치환 일자·결정 주체를 8장 이력표에 기록한다.

### 0.3 항목 번호 체계

`CP-{그룹}{일련번호}` 형식이다. 그룹은 성격별로 A(금액) / B(기간·일정) / C(수량·비율·임계) / D(정보·창구·식별자) / E(법무 문언) / F(게임 수치·검수 기준)로 나눈다. 총 **91항**이다.

| 그룹 | 성격 | 항목 수 | 주 확정 주체 |
|---|---|---|---|
| A | 금액 | 10 | 발주자 / 양자 합의 |
| B | 기간·일정 | 37 | 발주자 / 양자 합의 |
| C | 수량·비율·임계 | 12 | 발주자 |

### 0.4 확정 시한 구분

| 표기 | 뜻 | 도과 시 효과 |
|---|---|---|
| 공고 전 | 제안 요청 발송 이전 | 제안사가 견적·일정을 산출할 수 없어 제안 절차 자체가 성립하지 않는다 |
| 계약 전 | 계약서 서명 이전 | 계약서 문언이 비게 되어 해당 조항이 무효 또는 해석 불능이 된다 |
| 계약 시 | 계약서 서명 시점에 계약서 본문·부속으로 편철 | 편철 누락 시 검수 기준의 고정이 깨진다 |
| 킥오프 | 계약 발효 후 킥오프(개발 Phase 0 / 아트 5.2) 종료 시 | 제작 착수는 가능하나 해당 산출물의 검수가 불능이다 |
| Phase 0 | 개발 발주서 6.1 2)항 Phase 0 질의응답 회신 시 | 해당 AC의 판정이 보류된다(부속서 D-1.0 4항) |
| 게이트별 | 표기된 게이트 검수 개시 전 | 그 게이트의 해당 지표를 판정할 수 없다 |

## 8. 확정 순서 권고

확정은 **금액 → 일정 → 수량·법무 → 게임 수치**의 순서가 아니라, **의존 관계의 최상류부터** 풀어야 재작업이 없다. 최상류는 CP-X01(아트 발주 구조 A안/B안 택일)이다. 이 하나가 정해져야 개발 발주 예산 CP-A01의 범위(아트·사운드 포함 여부)가 정해지고, CP-A01이 정해져야 CP-A03 마일스톤별 금액과 CP-A04 지체상금 상한이 자동 산출되며, 아트를 분리하는 경우에만 CP-A05·CP-A06·CP-C08이 의미를 가진다. 두 번째 상류는 **개발 계약 체결 예정일 CP-B07**이다. 아트 5.7 1)이 아트 착수를 개발 W0의 2주 선행으로 고정했으므로, CP-B07을 못박아야 CP-B24(아트 계약 체결일)가 역산되고, 그로부터 CP-B17~B23의 아트 선정 60일 일정과 CP-B25~B29의 마일스톤 4개가 한 번에 결정된다. 반대로 아트 일정을 먼저 잡으면 개발 26주가 뒤로 밀릴 때마다 아트 마일스톤 전체를 다시 계산해야 한다. 세 번째는 **CP-D02 소재지**로, 이것이 CP-E01 관할 법원을 특정하고 나머지 법무 문언(CP-E03·E07·E08·E09·E10)의 검토 착수 조건을 완성한다 — 법무 검토는 리드타임이 가장 길므로 CP-D02 확정 즉시 CP-E 전 항목을 일괄 의뢰하는 편이 낫다. 네 번째는 **CP-B10/CP-B16 질의 회신 기한의 통일**이다. 이 값이 2영업일로 고정되어야 CP-B09(영향 평가 회신 5영업일)와 CP-C01·C02(경미 변경 기준)가 같은 시간 척도 위에서 설계되고, 부속서 D-3.3.1 5)항의 지연 면책 계산이 CP-A04 지체상금과 모순 없이 맞물린다. 마지막이 **그룹 F(게임 수치)**인데, 순서상 마지막일 뿐 시한은 가장 촉박하다 — Phase 0은 계약 발효 후 2주에 불과하고, CP-F01·CP-F03·CP-X02·CP-X03 네 항목은 전부 게이트 2 밸런스 재현(92.44점 ±0.01)의 전제이므로, 계약 협상 중에 발주자 내부 답을 미리 준비해 두고 Phase 0 질의응답에서 회신만 하는 방식이 안전하다. 요약하면 **CP-X01 → CP-A01 → CP-B07 → CP-D02 → CP-B10/B16 → 그룹 F**의 6단 순서이며, 나머지 항목은 이 6개가 정해지는 즉시 종속적으로 확정되거나 기재값 채택으로 처리된다.
