# 손미림 최신 의상·신장 변경본

고정 리비전 `AI-PROMPT-FINAL.md`(82bc5b0)를 기준으로 손미림의 최신 발주자 변경을 반영한 오버라이드다. 기존 R2 파일은 보존하며, 손미림 관련 최신 판정에서는 이 폴더를 우선 사용한다.

## 확정 변경

- 성인 여성, 키 150cm의 작고 컴팩트한 실루엣. 아동화·SD 재해석이 아니다.
- 하의는 일본식 통 넓은 와이드 팬츠. 허리부터 밑단까지 넓고 곧게 떨어지는 정돈된 실루엣이다.
- 상의는 타이트하고 몸에 맞는 셔츠. 넣어 입고 소매를 걷는다.
- 다섯 명 중 유일하게 옷을 제대로 갖춰 입은 사람이라는 축은 유지한다. 고급·하이패션이 아니라 다림질과 색 조합이 관리된 생활복이다.
- 카메라·플래너/클립보드·옷핀과 칼라 사이의 작은 가상 헤비메탈 티셔츠 슬리버는 유지한다.
- 겉 셔츠 그래픽, 목걸이, 펜던트, 명찰, 사원증, 랜야드, 목에 건 헤드폰은 넣지 않는다.
