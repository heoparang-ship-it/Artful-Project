# 이영림 · 인플루언서 고정안

## 적용 우선순위

이 폴더의 5개 파일이 이전 R2 패키지의 이영림 관련 파일을 대체한다. 기존 파일은 작업 이력 보존용으로 남겨 둔다.

## 고정 디자인

- 개인 채널을 운영하는 성인 콘텐츠 기획자
- 장발, 곧고 자신감 있는 자세
- 화려하게 정돈된 카메라용 운동복
- 허리까지 올라오는 하이넥 운동 상의와 매트한 트레이닝 재킷
- 무채색 기반의 통제된 포인트 컬러 블로킹
- 무릎 위에서 끝나는 짧고 불투명한 운동 레깅스
- 운동화, 가방 2개, 접이식 링라이트, 휴대폰과 보조배터리
- 목에는 글자 없는 무지 사원증과 클립 마이크

신체를 강조하는 표현과 실제 브랜드 로고는 넣지 않았다. 인상은 얼굴 이상화가 아니라 의상·헤어·소품·색 조합에서 읽히도록 했다.
