## 이번에 복구한 설계

### 손미림 — 09 이전 R2 안 (이력)

- 오버핏·와이드·배기 의상을 폐기했다.
- 다섯 명 중 유일하게 제대로 갖춰 입은 인물로 복구했다.
- 셔츠는 잘 맞고 소매를 걷어 넣어 입으며, 바지는 깔끔한 테일러드 트라우저, 신발은 단정한 구두다.
- 헤비메탈은 셔츠 안쪽 밴드 티에 숨겼고, 열린 칼라 사이로 글자 없는 가상 괴물 그래픽이 아주 조금만 보인다.
- 겉 셔츠에는 그래픽을 넣지 않았다.

### 손미림 — 최신 규칙 변경

- 키 150cm의 작고 컴팩트한 성인 여성 실루엣으로 조정했다. 아동화하지 않는다.
- 하의는 일본식 통 넓은 와이드 팬츠로 교체했다. 허리부터 밑단까지 넓고 곧게 떨어지는 정돈된 실루엣이다.
- 상의는 타이트하고 몸에 맞는 셔츠로 교체하고, 넣어 입은 뒤 소매를 걷었다.
- 다섯 명 중 유일하게 제대로 갖춰 입은 사람이라는 핵심은 유지한다. 고급·하이패션이 아니라 다림질과 색 조합이 관리된 생활복이다.
- 카메라·플래너/클립보드·옷핀, 칼라 사이의 작은 글자 없는 가상 헤비메탈 티셔츠 슬리버는 유지했다.
- 겉 셔츠 그래픽과 목걸이·펜던트·명찰·사원증·랜야드·목에 건 헤드폰은 넣지 않았다.
- `09_sonmirim_widepants_fixed`의 5개 파일을 최신 손미림 우선 사용본으로 지정한다.

### 이영림 — 이전 R2 안 (이력)

- 날씬함·피트니스 인플루언서·레깅스·상하의 통일을 폐기했다.
- 평범한 체형의 콘텐츠 기획·스토리 디렉터로 복구했다.
- 상의는 카메라용으로 정돈된 블라우스, 하의는 현장용 헐렁한 낡은 트랙 바지와 낡은 운동화다.
- 상·하의가 서로 다른 날의 옷처럼 보이도록 분리했다.
- 장발과 곧은 자세는 앞선 사용자 지시를 유지했다.

### 이영림 — 최신 규칙 변경

- 이전 `07_leeyeonglim_influencer_fixed`의 가방·명찰·마이크·보조 장비 규칙을 폐기했다.
- 최신 고정안에서 들고 다니는 물건은 휴대폰 1개와 조명 1개뿐이다.
- 성인 운동복의 어깨·소량 복부 노출을 허용했으며, 전문적인 피트니스 촬영복으로 처리했다.
- `08_leeyeonglim_phone_light_fixed`의 캐릭터 시트·표정·밤·라인업·SD를 `07`보다 우선 사용한다.

### 목 소품

제거하지 않고 카드 면과 태그 면만 무지 처리했다.

- 이영림: 빈 사원증 + 클립 마이크
- 김신입: 빈 사원증
- 이혜미: 글자·로고 없는 검은 클로버 펜던트
- 요청 대상에 포함되지 않은 손미림은 목걸이·명찰을 복원하지 않았고, 헤드폰도 목에 두지 않았다.
