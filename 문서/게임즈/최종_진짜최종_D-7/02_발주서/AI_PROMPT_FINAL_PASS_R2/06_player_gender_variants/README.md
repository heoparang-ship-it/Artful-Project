# 김신입 플레이어 성별 선택형

## 범위

김신입은 시작 시 남성/여성을 선택하는 플레이어 캐릭터다. 아래 두 이미지는 같은 원판에서 얼굴과 머리 모양만 달리한 전신 캐릭터 시트다.

- [남성 버전](./ch_kimsinip_male_sheet_prompt_final.png)
- [여성 버전](./ch_kimsinip_female_sheet_prompt_final.png)

## 공통 원판

- 같은 oversized cheap jacket, plain shirt and trousers, worn sneakers
- 같은 어깨 위 케이블 뭉치
- 같은 토트백과 숄더백
- 같은 팔 아래 필름 슬레이트
- 같은 벨트 루프의 SSD·카드리더·카라비너
- 같은 가슴의 무지 사원증과 스트랩 형태
- 같은 작은 형체, 약간 숙인 자세, 장비에 파묻힌 외곽 실루엣

사원증 면은 평평한 색 사각형이며 글자·사진·로고·기호를 넣지 않았다. 두 버전의 순흑 실루엣은 성별이 아니라 짐과 외곽선으로 읽혀야 한다.

## 얼굴·머리 차이

- 남성: 20대 중반 남성, 평범하고 피곤한 인상, 짧고 조금 자란 값싼 헤어컷
- 여성: 20대 중반 여성, 평범하고 피곤한 인상, 대충 묶은 머리와 빠져나온 잔머리

## 제작 범위 제외

- 대화창 초상: 제작하지 않음
- 표정 시트: 제작하지 않음
- 이 폴더의 두 이미지는 방향 합의용 전신 레퍼런스이며 최종 납품 에셋이 아님
