# plates — 게임에 바로 들어가는 이미지

여기에 파일을 넣고 `node ../../04_MVP프로토타입/build-artifact.mjs`를 돌리면
게임이 그리던 도형 대신 **이 그림을 씁니다.** 없는 것만 도형으로 그립니다.

## 파일 이름 (이 이름 그대로)

| 파일 | 쓰이는 곳 | 권장 규격 |
|---|---|---|
| `office-day.png` | 사무실 씬 — 낮 배경판 | 1120×430 이상, 가로세로비 유지 |
| `office-night.png` | 사무실 씬 — 밤(이면) 배경판 | 동일 |
| `crew-heo.png` | 허파랑 — 서 있는 전신 | 배경 투명 PNG, 세로 400px 이상 |
| `crew-lyl.png` | 이영림 | 동일 |
| `crew-lhm.png` | 이혜미 | 동일 |
| `crew-smr.png` | 손미림 | 동일 |
| `crew-you.png` | 나(신입 AP) | 동일 |
| `title.png` | 타이틀 키비주얼 | 1920×1080 |

- **인물은 배경 투명 PNG**여야 합니다. 배경이 있으면 사각형으로 얹힙니다
- 인물은 **발끝이 이미지 아래 끝에 닿게** 잘라주세요. 그 기준으로 바닥에 세웁니다
- `.png` / `.jpg` / `.webp` 다 됩니다
- 파일이 없으면 그 항목만 기존 도형 렌더링으로 돌아갑니다 — 하나씩 넣어도 됩니다

## 이 이미지의 지위

프리비즈·프로토타입용입니다. 아트 발주서 §1-2에 따라 **최종 납품 에셋은
작가의 작업물**이어야 하며, 생성형 AI 산출물을 그대로 납품할 수 없습니다.
여기 들어간 파일이 AI 생성물이라면 사용 도구와 구간을 고지해야 합니다.
