## 최종 캐릭터 디자인 요약

### 01_허파랑 (Heoparang)
- 나이: 39세
- 표정: 지쳐있음
- 안경: 동그란 레옹 스타일 안경
- 상의: 형광색 스포티 반팔 티셔츠
- 하의: 청바지
- 소지품: 태블릿
- 스타일: 웹툰 클립아트, 배경 없음

### 02_이영림 (Lee Yeonglim)
- 얼굴: 4명 중 가장 화려함
- 체형: 가슴 크게
- 상의: 검은 스포츠 브라
- 하의: 검은 쇼츠 (HDEX 스타일, 로고 없음)
- 소지품: 핑크 짐백 + 스마트폰
- 스타일: 웹툰 클립아트, 배경 없음

### 03_이혜미 (Lee Hyemi)
- 얼굴: 날카롭고 예민한 평범한 얼굴
- 머리: 항상 지저분한 묶음머리
- 표정: 짜증남
- 체형: 매우 마름
- 상의: 검은 스키니 반팔 티셔츠
- 하의: 스키니 청바지
- 신발: 디올 패러디 슬리퍼
- 액세서리: 검은 클로버 목걸이
- 스타일: 웹툰 클립아트, 배경 없음

### 04_손미림 (Son Mirim)
- 얼굴: 귀여운 평범한 얼굴
- 머리: 단발머리
- 상의: 타이트한 흰 티셔츠 + 과장된 헤비메탈 로고
- 하의: 엄청 큰 가방바지
- 소지품: 카메라
- 스타일: 웹툰 클립아트, 배경 없음
