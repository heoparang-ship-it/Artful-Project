## 30초 피치

평범한 서울 근교 재건축 예정 아파트 103동 4층. 어느 오후 **위급재난문자**가 울린다.
정체를 알 수 없는 유독성 강하분진 **「회백(灰白)」**이 서해에서 밀려오고 있다. 도달까지 **120초**.

플레이어는 32평 집을 뛰어다니며 라면, 생수, 소화함 도끼, 할머니 혈압약, 보조배터리를 챙기고
**할머니·아내·고3 딸·초등학생 아들·반려견 중 데려갈 수 있는 만큼만** 데리고
아파트 지하 3층 **민방위 대피소**로 내려간다.

그리고 진짜 게임이 시작된다. 대피소에는 **우리 가족만 있지 않다.**

## 원작에서 무엇을 가져오고, 무엇을 바꿨는가

| 축 | 60 Seconds! (원작) | 『실제 상황입니다』 (본작) | 변경 의도 |
|----|-------------------|--------------------------|----------|
| 재난 | 1950년대 냉전기 핵전쟁 | 근미래 원인미상 강하분진 「회백」 | 미세먼지·재난문자·마스크 문화와 직결된 한국적 체감 |
| 경고 | 사이렌, 60초 | 위급재난문자 + 민방위 사이렌, **120초** | 4층→지하 3층 **수직 이동**과 다인 가구 설득 시간 확보 |
| 수집 공간 | 절차생성 단독주택 1층 | 절차생성 32평 아파트 + **공용 복도/계단/소화함** | 한국 주거 형태 반영, 세로 동선 추가 |
| 대피 공간 | 사유 방공호 (텅 빈 상태) | 아파트 **민방위 대피소** (주민 창고로 쓰여 **잡동사니 선점**) | 초기 물자에 변수, 대피소 자체를 탐색 대상으로 |
| 파티 | 가족 4인 고정 | 가족 **5인 + 반려견**, 주인공 선택 가능 | 3세대 가구 → 트리아지 난이도 상승 |
| 밀실 구성 | 우리 가족만 | **이웃 최대 5명 합류** | ★ 핵심 차별화: 자원관리 → **공동체 정치** |
| 사회 시스템 | 없음 | **신뢰도 + 반상회 투표 + 단톡방 여론** | 한국형 갈등 드라마와 블랙코미디의 엔진 |
| 정보 채널 | 라디오 | 라디오 + **스마트폰 단톡방(배터리 소모)** | 정보 획득에 자원 비용 부과 |
| 조리 | 통조림 즉시 취식 | 라면·햇반 = **물 + 부탄가스 + 환기** 필요 | ★ 열원/환기/오염의 3중 트레이드오프 |
| 만성질환 | 없음 | **처방약(혈압/천식/인슐린) 정기 소모** | 고령 가족이 있는 한국 가구의 현실 압력 |
| 상태이상 | 방사능병/발열/부상/벌레/광기 | **회백폐/발열/부상/해충/불안·공황** + 신뢰붕괴 | 원작 계승 + 사회적 실패 상태 추가 |
| 엔딩 | 구조 / 실패 / 특수 | **16종** (구조 4 / 자립 3 / 이주 3 / 붕괴 4 / 비밀 2) | 공동체 축으로 분기 확장 |
| 톤 | 미국 50년대 레트로 블랙코미디 | **90~00년대 한국 아파트 레트로 블랙코미디** | 관리비·층간소음·분리배출·반상회 유머 |

> 원작의 재미 구조(**절차생성 트리아지 → 정보 불완전 상태의 배급 도박 → 이벤트 덱 서사 → 다중 엔딩 수집**)는 그대로 계승한다.
> 바꾼 것은 **"밀실에 남이 있다"** 는 단 하나의 전제이며, 여기서 본작의 모든 신규 시스템이 파생된다.

## 설계 원칙 5가지

1. **모든 자원은 다른 자원의 값을 매긴다.** 라면은 식량이지만 물과 가스를 먹고, 가스는 환기를 요구하고, 환기는 회백을 들인다. 단일 최적해가 없어야 한다.
2. **정보에 값을 매긴다.** 무엇이 밖에서 벌어지는지 아는 것 자체가 배터리·시간·신뢰를 소모하는 유료 행위다.
3. **실패는 사망이 아니라 서사다.** 굶어 죽는 것보다 **이웃에게 쫓겨나는 것**이 더 자주 일어나야 한다.
4. **웃기다가 서늘해야 한다.** 지하에서도 분리배출을 하는 이웃은 웃기지만, 그 이웃이 배급표를 조작하면 서늘하다.
5. **1회차는 반드시 실패한다.** 대신 실패의 원인이 명확히 회수되어 다음 회차의 계획이 되어야 한다.
