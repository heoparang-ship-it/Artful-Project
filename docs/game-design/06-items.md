# 06. 아이템 데이터 (78종)

## 표기 규칙

- **부피**: 운반 슬롯 점유 수 (1 = 한 손, 2 = 부피 아이템)
- **스폰**: 수집 단계에서의 등장 확률 (노멀 난이도 기준). ★ = 보장 스폰 대상
- **탐색**: 외출 탐색으로 재획득 가능한 주 목적지
- 게이팅(gating) 아이템은 **★G** 로 표시 — 없으면 특정 이벤트에서 즉사 또는 회복 불가
