# 05. 캐릭터 — 가족 5인 + 반려견 + 이웃 14종

## 1. 설계 원칙

1. **모든 캐릭터는 이득과 비용을 동시에 가진다.** "데려가면 무조건 좋은 사람"은 없다.
2. **비용은 자원, 이득은 선택지.** 특성은 수치 보너스보다 **이벤트 선택지 추가**로 주는 것을 우선한다 (서사가 남는다).
3. **한국 가구의 실제 구성을 반영한다.** 3세대 동거, 고3 수험생, 반려동물, 만성질환.
4. **사망은 시스템 손실이 아니라 서사 손실이 되도록** 각 캐릭터에게 고유한 사후 효과를 준다.
