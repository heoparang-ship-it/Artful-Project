# 04. ★ 공동체 시스템 — 신뢰도 · 반상회 · 단톡방 · 탐색

> 원작은 **가족 4인의 고립**을 다룬다. 본작은 **아파트 공동체의 밀착**을 다룬다.
> 이 문서의 시스템들이 본작을 *60 Seconds! 한국 리스킨*이 아닌 **다른 게임**으로 만드는 부분이다.

---

## 1. 신뢰도 (Trust)

### 1-1. 정의
대피소에 함께 있는 **비(非)가족 인원 전체가 우리 가족을 어떻게 보는가**를 나타내는 단일 수치. 0~100.

- 이웃이 0명이면 신뢰도 시스템은 비활성 (= 원작 모드에 가까운 플레이)
- 이웃이 1명이라도 있으면 활성. **이웃 수가 많을수록 변동폭이 커진다** (변동 × (1 + 0.15 × 이웃수))

### 1-2. 초기값

| 조건 | 초기 신뢰도 |
|------|-----------|
| 기본 | 50 |
| 주인공이 동대표(김대호) | +10 |
| 이웃 세대 문을 도끼로 부수고 들어감 | -20 |
| 이웃의 요청(아이만 데려가기)을 수락 | +10 |
| 지연 합류 이웃을 위해 문을 열어줌 | +10 |
| 문 앞에서 거절한 이웃이 나중에 합류 | -15 |
| 재건축 반대파 이웃 + 우리 집이 찬성파 | -10 (설정 롤) |

### 1-3. 변동 요인

| 상승 | 값 | 하락 | 값 |
|------|-----|------|-----|
| 균등 배급 유지 | +2/일 | 가족 우대 배급 (발각 시) | **-12/일** |
| 아픈 이웃 치료 (약 소모) | +12 | 아픈 이웃 방치 3일 | -10 |
| 탐색 성과 전량 공개 | +8 | 탐색 성과 은닉 (발각 시) | **-18** |
| 반상회 의결 이행 | +6 | 반상회 의결 위반 (발각 시) | -20 |
| 이웃에게 오락 제공 | +4 | 이웃 창고 무단 개방 | -8 (주인 있으면 -25) |
| 위험한 탐색을 우리 가족이 담당 | +10 | 이웃에게만 탐색 강요 | -8 |
| 이웃 사망 (구조 시도했음) | -5 | 이웃 사망 (방치했음) | **-25** |
| 반려견이 이웃 아이를 달램 | +3 | 반려견이 이웃을 물음 | -10 |
| 정보(단톡방/라디오) 공유 | +5 | 정보 독점 (발각 시) | -10 |

### 1-4. 발각 판정 (은닉 메커니즘)
비공정한 행동은 즉시 들키지 않는다. **매일 발각 롤**이 돈다.

```
발각확률 = 기본치 × (1 + 0.2 × 이웃수) × 은닉보정
  기본치:   가족 우대 배급 35% / 탐색 성과 은닉 25% / 의결 위반 40%
  은닉보정: 자물쇠 창고 확보 시 ×0.5, 「눈치 빠른 이웃」 있으면 ×1.6
            고3 딸 「알리바이」 특성 발동 시 ×0.6
```
- 발각 시 하락값이 **누적 일수만큼 한 번에** 적용된다 → 오래 숨길수록 파멸적
- 발각 즉시 「배급 장부 감사」 이벤트 강제 발생

### 1-5. 신뢰도 구간별 효과

| 구간 | 상태 | 효과 |
|------|------|------|
| **85~100** | 「우리 단지」 | 배급 소모 -10% (나눠 먹기 효율), 탐색 2인 파견 가능, 이웃 특성 상시 발동, 이웃이 자기 물자 공개 |
| 65~84 | 협력적 | 이웃 특성 사용 가능, 탐색 지원 |
| 40~64 | 중립 | 기본 |
| 25~39 | 「불신」 | 물자 도난 15%/일, 이웃 특성 사용 불가, 반상회 안건 통과 어려움 |
| 10~24 | 「적대」 | 도난 35%/일, 이웃 파벌 형성, **축출 안건 상정** |
| **0~9** | 「축출」 | 3일 내 축출 투표 → 가결 시 **엔딩 「의결」** (게임오버) |

> **본작의 대표적 패배는 굶어 죽는 것이 아니라 쫓겨나는 것이다.**
> 플레이테스트 목표: 초회 10회차 내 실패 원인 중 **신뢰도 붕괴가 30~40%** 를 차지하도록 튜닝.

## 2. 반상회 (입주자대표회의)

### 2-1. 발생
- **3일차, 이후 5일마다** 자동 발생 (이웃 1명 이상 시)
- 추가로 대형 사건 직후 긴급 반상회 발생 (사망, 도난 발각, 침입, 정부 발표 정정)

### 2-2. 진행

```
┌───────── 긴급 반상회 (8일차) ─────────┐
│ 참석  6명 (우리 4 / 403호 2)          │
│ 의장  김대호 (동대표)                  │
├───────────────────────────────────────┤
│ 안건 제2호                             │
│ 「어린이·노약자 우선 배급의 건」       │
│                                        │
│ ① 찬성 발언  (설득 판정: 사기+신뢰)    │
│ ② 반대 발언                            │
│ ③ 수정 제안 — "아픈 사람 우선으로"     │
│ ④ 기권                                 │
├───────────────────────────────────────┤
│ 예상 표결   찬 3 · 반 2 · 부동 1       │
└───────────────────────────────────────┘
```

- **표결은 인원별 개인 성향 + 사기 + 신뢰도**로 계산된다. 부동표를 설득하는 것이 플레이 목표.
- 의장(동대표) 특성 보유 시 **가부동수일 때 결정권**
- 설득 판정 성공률: `40% + 신뢰도×0.4 + 주인공사기×0.2 + 특성보정`

### 2-3. 안건 풀 (14종)

| # | 안건 | 가결 시 효과 | 위반 시 |
|---|------|-------------|--------|
| 1 | 균등 배급의 건 | 전원 동일 배급 강제, 신뢰 +2/일 | 신뢰 -20 |
| 2 | 어린이·노약자 우선의 건 | 아동/노인 정량 고정, 성인 절식 | 신뢰 -20 |
| 3 | 노동자 우선의 건 | 탐색·정비 담당자 정량, 나머지 절식 | 액션 성공률 +10% |
| 4 | 병자 우선의 건 | 환자 정량 + 약 우선 배정 | 신뢰 -15 |
| 5 | 물자 통합 관리의 건 | 전 물자 공개 → 은닉 불가, 이웃 물자 +30~60% 편입 | — |
| 6 | 개인 창고 개방의 건 | 자물쇠 8칸 합법 개방 | — |
| 7 | 외출 담당 지정의 건 | 지정 인원만 탐색. 지정자 사망 시 신뢰 -20 | — |
| 8 | 야간 소음 금지의 건 | 밤 오락 금지 (사기 -3/일), 침입 유발 확률 -50% | 신뢰 -10 |
| 9 | 환기 시간 지정의 건 | 환기 자동화(1일 1회 부분), 회백 +3/일 고정 | — |
| 10 | 분리배출 실시의 건 | 악취/해충 확률 -60%, 액션 1 상시 소모 | 신뢰 -8 |
| 11 | 외부인 수용 원칙의 건 | 문 앞 이벤트 시 자동 수용/거절 결정 | — |
| 12 | 반려동물 처리의 건 | 부결 시 또리 유지 / 가결 시 또리 유기 (가족 사기 -25) | — |
| 13 | 관리비 정산의 건 (코미디) | 현금·귀금속 물자를 "관리비"로 징수, 신뢰 +10 | — |
| 14 | **404호 축출의 건** | 가결 시 게임오버 엔딩 「의결」 | — |

> 안건 13번은 순수 블랙코미디다. 세상이 끝났는데 관리비를 정산하려는 이웃.
> 그런데 그 절차를 지켜주면 신뢰도가 오른다. **웃기면서 시스템으로 유효한 것**이 본작의 유머 기준이다.

### 2-4. 스트리머 모드
반상회 표결이 발생하면 **시청자 채팅 투표로 부동표를 결정**한다.
- `!찬성` / `!반대` 명령어, 30초 집계
- 회차당 3~7회 발생 → 실황 참여 지점 구조적 보장
- 이 기능은 마케팅 부산물이 아니라 **국내 인디의 주 유입 채널에 맞춘 설계 결정**이다.

## 3. 단톡방 (정보 시스템)

### 3-1. 개요
「새빛3단지 103동 입주민방 (128)」 — 재난 전부터 있던 아파트 단톡방.
전기는 끊겼지만 통신망은 3~9일차까지 간헐적으로 살아 있다.

| 항목 | 규칙 |
|------|------|
| 열람 비용 | 전력 0.2 / 회 (스마트폰 배터리) |
| 열람 가능 | 1~9일차 상시 / 10~14일차 확률 40% / 15일차+ 불가 (기지국 정지) |
| 획득 정보 | 구조대 일정, 다른 동 상황, 상가·약국 재고, 외부인 무리 경고, 안전구역 좌표 |
| 정보 신뢰도 | 각 메시지에 **진짜 / 소문 / 허위** 태그가 숨겨져 있다 |
| 판별 | 고3 딸의 「정보 판별」 특성 또는 라디오 교차검증으로 태그 일부 공개 |
| 여론 | 단톡방 여론이 **신뢰도에 ±5까지 영향** (우리 가족에 대한 소문이 돈다) |

### 3-2. 단톡방 연출 예시

```
새빛3단지 103동 입주민방 (128)                     6일차
───────────────────────────────────────────────
[102동 김실장]  구조대 명단 나왔다는데 우리 단지 12번째래요
                                        [소문]
[동대표 최]     확인 안 된 얘기 올리지 마세요
[1204호]        상가 약국 셔터 안 잠겨 있어요. 아직 남아 있음
                                        [진짜]
[미확인]        학교 대피소로 오세요. 자리 있습니다
                                        [허위]
[502호 엄마]    404호는 물이 많은가 봐요? 아까 페트병 소리가...
                                        ← 신뢰도 -4
[1001호]        확인했습니다 👍
[1001호]        확인했습니다 👍
[1001호]        확인했습니다 👍
───────────────────────────────────────────────
      [ 읽기만 ]  [ 답장하기 ]  [ 나가기 ]
```

- `[답장하기]`: 신뢰도/사기에 영향. 해명하면 신뢰 +3, 무시하면 -2, 화내면 -8
- 「1001호」의 확인했습니다 도배는 회차마다 반복되는 러닝 개그이며, 후반에 **1001호가 이미 사망했다는 사실이 밝혀진다.**
  (자동 응답 아니었다. 누가 그 폰을 쓰고 있는가 → 비밀 엔딩 단서)

### 3-3. 라디오와의 관계

| 채널 | 비용 | 정보 성질 |
|------|------|----------|
| 단톡방 | 전력 0.2 | 국지적·구체적·**신뢰도 불명** (상가 재고, 다른 동 상황) |
| 라디오(공식 방송) | 전력 0.1 or 건전지 | 광역적·추상적·**신뢰 가능** (구조 일정, 정부 발표) |
| 라디오(해적방송) | 전력 0.1 | 음모론, 안전구역 좌표, **비밀 엔딩 단서** |
| 관리사무소 방송설비 | 전력 2 + 접근 필요 | **송신 가능** → 구조 좌표 송신 → 구조일 15~19일로 단축 |

> **정보의 3원 구조:** 국지 정보(단톡방)는 싸지만 못 믿고, 광역 정보(라디오)는 믿을 수 있지만 두루뭉술하고,
> 진짜 판단은 **두 채널을 교차 검증**해야 나온다. 그리고 교차 검증은 전력을 두 배로 쓴다.

## 4. 외출 탐색 (Scavenging Run)

### 4-1. 기본 규칙

| 항목 | 규칙 |
|------|------|
| 가능 시점 | 2일차부터, **3일 간격** (같은 인원 재파견은 5일 간격) |
| 파견 인원 | 1명 (신뢰도 85+ 시 2명) |
| 소요 | 1~3일 (목적지별). 부재 중 해당 인원의 액션 기여 없음 |
| 장비 슬롯 | 3칸 (방호 / 도구 / 용기) |
| 귀환 | 물자 최대 6칸 (배낭·캐리어 있으면 +3) |

### 4-2. 목적지

| 목적지 | 소요 | 위험 | 주요 획득 | 특수 |
|--------|------|------|----------|------|
| 우리 집 (404호) | 1일 | 낮음 | 수집 단계에서 못 챙긴 아이템 **그대로 남아 있음** | ★ 1회차 실수 회수 지점 |
| 4층 이웃 세대 | 1일 | 낮음 | 랜덤 물자 3~6 | 신뢰도 -5 (남의 집) |
| 지하 1층 관리사무소 | 1일 | 중간 | **마스터키, 방송설비, 세대 도면, 비상발전기** | ★ 구조 단축의 핵심 |
| 지하주차장 | 1일 | 중간 | 자동차 배터리, 경유, 트렁크 물자, 공구 | 차량 롤 5대 |
| 단지 상가 (편의점/약국) | 2일 | 높음 | **식량 대량, 약, 담배, 주류** | 선점 여부 롤. 다른 생존자 조우 |
| 옆 동 (102동) | 2일 | 높음 | 물자 + **이웃 영입 기회** | 다른 대피소 공동체와 교섭 |
| 초등학교 대피소 | 3일 | 매우 높음 | 정부 구호물자, 정보 | ★ 「이주」 엔딩 사전 조사 |
| 하천 / 취수장 | 3일 | 매우 높음 | 물 대량 (오염) | 회니 노출 극심 |

### 4-3. 결과 판정

```
성공률 = 60%
       + 담당자 특성 보정 (라이더 +15 / 예비군 +10 / 경비원 +10 / 노인 -20)
       + 장비 보정 (지도 +10 / 손전등 +8 / 방독면 +5 / 도끼 +8)
       + 신뢰도 보정 (85+ 시 +10, 25 이하 시 -10)
       − 상태 보정 (허약 -25 / 부상 -30 / 사기 30 이하 -15)
       − 목적지 위험도 (0 / -10 / -20 / -30)
```

| 결과 | 내용 |
|------|------|
| 대성공 (판정+20 초과) | 물자 만재 + 특수 아이템 + 정보 1건 |
| 성공 | 물자 획득 |
| 부분 성공 | 물자 절반 + 경상(부상) |
| 실패 | 물자 없음 + 부상 또는 회백 노출 대량 |
| 대실패 | **미귀환** — 3일 후 20% 확률로 귀환, 아니면 사망 처리 |

### 4-4. 탐색의 도덕 축
- **누구를 보내는가**가 신뢰도의 최대 입력값이다.
- 이웃만 계속 보내면 신뢰도 -8/회. 우리 가족을 보내면 +10/회.
- 아픈 사람을 보내면 신뢰도 -15, 성공률 -30%.
- 그런데 우리 가족을 보내면 우리 가족이 다친다. **정직함에는 가격이 붙어 있다.**

## 5. 문 앞 방문자 (외부인 시스템)

원작의 "문 밖의 목소리"를 공동체 의사결정으로 확장한다.

| 방문자 | 빈도 | 수용 시 | 거절 시 |
|--------|------|--------|--------|
| 지연 합류 이웃 | 1~2일차 | 인원 +1, 신뢰 +10, 회백 +3 | 신뢰 -10 |
| 다른 동 가족 (3인) | 5~12일차 | 인원 +3(소모 급증), 물자 +2, 신뢰 +15 | 신뢰 -8, 6일 후 재방문 없음 |
| 부상자 1명 | 4~15일차 | 약 즉시 소모, 신뢰 +18 / 방치 시 -20 | 신뢰 -15, 사기 -8 |
| **구조대 사칭 사기** | 8~20일차 | 문 개방 → 물자 40% 강탈 + 부상 | 신뢰 -3 (이웃 일부는 진짜라고 믿음) |
| 약탈 무리 (3~5인) | 10일차+ | 문 개방 = 파멸 | **무기 필요** (없으면 문 파괴 → 엔딩) |
| 정부 조사팀 | 12일차+ | 정보 + 물자, 인원 검사 (회백폐 환자 격리 요구) | 정보 상실 |
| 종교 단체 | 6일차+ | 사기 +15 / 물자 -3, 이후 포교 이벤트 연쇄 | 사기 -5 |
| **반려동물만** | 랜덤 | 사기 +10, 식량 소모 +0.5 | 사기 -12 (아동 -20) |

- **판별 단서:** 사칭 사기는 대사에 미묘한 오류가 있다 (단지명 오기, 존재하지 않는 부서명).
  단톡방/라디오 정보를 보유하면 **선택지에 「그런 부서 없는데요」 가 추가된다.**
- 반상회 안건 11번(외부인 수용 원칙)이 가결되어 있으면 자동 처리 → 플레이어가 판단을 포기하는 대신 신뢰도를 얻는다.

## 6. 시스템 상호 연결도

```
        ┌──────────── 수집 단계 ────────────┐
        │  이웃 몇 명 데려왔는가?           │
        └──────────────┬───────────────────┘
                       ↓
       ┌───────────────────────────────────┐
       │  이웃 수 N                         │
       │   ├─ 소모 +N (식량/물)             │  ← 압력
       │   ├─ 액션 +1~2                     │  ← 이득
       │   ├─ 특성 N개 (마스터키/의료/…)    │  ← 이득
       │   ├─ 신뢰도 변동폭 ×(1+0.15N)      │  ← 리스크
       │   └─ 반상회 표결 참여              │  ← 통제 불능
       └──────────────┬────────────────────┘
                      ↓
   ┌──────────────────────────────────────────┐
   │  배급 결정  ⇄  신뢰도  ⇄  반상회 규칙    │
   │       ↕            ↕            ↕        │
   │    사기    ⇄   단톡방 여론  ⇄  이벤트   │
   │       ↕            ↕                     │
   │    탐색 담당  ⇄  전력(정보)              │
   └──────────────────┬───────────────────────┘
                      ↓
        구조 / 자립 / 이주 / 붕괴 / 축출
```

> **설계 검증 기준:** 어떤 자원도 단독으로 최적화할 수 없어야 한다.
> 물을 아끼면 라면을 못 끓이고, 라면을 끓이면 환기해야 하고, 환기하면 폐가 상하고,
> 폐가 상하면 탐색을 못 가고, 탐색을 못 가면 물이 없다.
> 그리고 그 모든 결정을 **여섯 명이 지켜보고 있다.**
