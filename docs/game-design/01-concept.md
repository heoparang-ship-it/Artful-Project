# 01. 컨셉 · 세계관 · 포지셔닝

## 1. 원작 해부 — *60 Seconds!* 는 왜 재미있는가

한국판을 기획하기 전에 원작의 재미를 4개 축으로 분해했다. 본작은 이 4축을 전부 유지하되, 축마다 한국적 압력을 하나씩 추가한다.

### 축 A. 절차생성 트리아지 (수집 단계)
매번 집 구조와 아이템 배치가 바뀌므로 **"무엇을 포기할지"를 매번 새로 판단**해야 한다. 최적 루트 암기가 통하지 않는다.
- 원작의 긴장 원천: 시간(60초) × 운반 제약(양손 + 여행가방) × 가족 4인
- 원작의 결정적 순간: 도끼를 챙길까, 아이를 데려갈까

### 축 B. 정보 불완전 상태의 배급 도박 (생존 단계)
**구조가 며칠 뒤에 올지 모른다.** 그래서 배급률을 정할 수 없다. 아껴 먹으면 허약해지고, 정량으로 먹으면 20일차에 바닥난다.
- 원작의 긴장 원천: 알 수 없는 종료 시점 + 감소만 하는 자원
- 원작의 결정적 순간: 오늘 물을 줄까, 3일 뒤를 위해 참게 할까

### 축 C. 이벤트 덱이 만드는 서사 (일지)
매일 뽑히는 카드가 "우리 가족의 이야기"로 읽힌다. 시스템이 아니라 **일지 텍스트**가 감정을 만든다.
- 원작의 긴장 원천: 게이팅 아이템(도끼 없으면 침입 이벤트 즉사) + 선택지의 정답 은닉
- 원작의 결정적 순간: 문 밖의 목소리를 믿을까

### 축 D. 다중 엔딩 수집 동기
짧은 회차 + 다양한 결말 = **"이번엔 다르게 해볼까"**. 실패도 하나의 엔딩으로 카운트되어 실패가 보상이 된다.

### 원작의 구조적 한계 (본작의 기회)
| 한계 | 본작의 대응 |
|------|------------|
| 중반부(8~15일차)에 할 일이 사라져 "탐색 → 대기" 반복 | 공동체 신뢰도 관리가 매일의 능동적 과제로 상주 |
| 자원이 감소만 함 → 후반은 결정이 아니라 소화 | 정수/발전/재배 **생산 트리**로 후반에 역전 가능성 부여 |
| 갈등이 전부 외부(문 밖)에서 옴 | 갈등의 절반을 **내부(밀실 안 이웃)** 로 이동 |
| 세계가 4인으로 닫혀 있음 | 단톡방·라디오로 **단지 전체·도시 전체**의 상황이 흘러들어옴 |

## 2. 한국화 전환 논리

핵심 질문은 "핵전쟁을 무엇으로 바꿀까"가 아니라 **"한국인에게 60초의 공포를 주는 신호는 무엇인가"** 였다.

### 2-1. 경고 신호 = 위급재난문자
한국인이라면 누구나 아는 **삐빅- 하는 위급재난문자 경보음**. 폭우, 지진, 산불, 실종. 매년 몇 번씩 실제로 울린다.
- 게임 오프닝은 **소리 하나로 시작한다.** 로고 없음, 음악 없음. 거실 소파에 앉아 있는데 온 가족 스마트폰이 동시에 진동한다.
- 그 다음 창밖에서 **민방위 사이렌**. 방송: *"지금은 실제 상황입니다."* → 타이틀 등장.

### 2-2. 대피 공간 = 아파트 지하 민방위 대피소
한국의 아파트 지하는 법적으로 **민방위 대피시설**로 지정돼 있다. 그리고 실제로는 **주민 창고**로 쓰인다.
이 이중성이 본작의 설계 자산이다.
- 벙커처럼 "내가 준비해 둔 안전한 곳"이 아니다. **먼지 쌓인 자전거, 남의 김치냉장고, 유모차, 깨진 형광등**이 있는 곳.
- 즉 **초기 물자에 절차생성 변수가 하나 더 붙는다.** (03 문서의 「선점 물자」 롤)
- 그리고 무엇보다 — **공용 공간이므로 남이 온다.**

### 2-3. ★ 결정적 전환: "밀실에 남이 있다"
원작은 단독주택 → 사유 방공호 → **핵가족의 고립**이다.
한국은 아파트 → 공용 대피소 → **공동체의 밀착**이다.

이 한 줄의 전환에서 본작의 모든 신규 시스템이 파생된다.

```
밀실에 남이 있다
├── 자원을 나눠야 한다        → 배급 공정성 / 신뢰도
├── 규칙을 정해야 한다        → 반상회 투표 시스템
├── 여론이 형성된다           → 단톡방 (배터리 소모)
├── 남의 능력을 쓸 수 있다    → 이웃 특성 (마스터키, 의료, 오토바이)
├── 남이 아프면 내 약이 준다  → 도덕적 딜레마의 상수화
└── 쫓겨날 수 있다            → 사망이 아닌 새로운 패배 조건
```

### 2-4. 조리 = 한국식 열원/환기 트레이드오프
원작의 수프 통조림은 **따서 먹으면 끝**이다. 한국의 주력 비상식량은 **라면과 즉석밥**이며 둘 다 조리를 요구한다.
- 라면 = 식량 2끼분이지만 **물 1 + 부탄가스 1 + 환기 1회** 필요
- 생라면으로 부숴 먹으면 물·가스 0이지만 **갈증 +1, 사기 -2**
- 밀폐된 지하에서 부르스타를 쓰면 산소가 준다 → **환기구를 열어야 한다** → **회백이 들어온다**

원작의 "먹는다"가 본작에서는 **4개 자원을 동시에 저울질하는 결정**이 된다. 이것이 본작 자원 설계의 심장이다.

### 2-5. 만성질환 = 한국 3세대 가구의 압력
할머니의 혈압약, 아들의 천식 흡입기. 이것은 아껴 쓸 수 없는 자원이다.
**"굶기는 건 조절할 수 있지만 약은 조절할 수 없다"** → 탐색을 강제하는 시한폭탄.

## 3. 세계관 설정

### 3-1. 재난 — 「회백(灰白)」

| 항목 | 설정 |
|------|------|
| 정부 공식 명칭 | 제1급 대기재난 (강하분진) |
| 시민 통칭 | 회백(灰白), 줄여서 「재」 |
| 발생 | 특정 오후, 서해 상공에서 관측. 편서풍을 타고 수도권으로 유입 |
| 외형 | 아주 고운 회백색 분진. 눈처럼 내리지만 소리 없이 쌓인다. 낮이 흐린 저녁처럼 변한다 |
| 인체 영향 | 흡입 시 폐 하부에 침착 → 축적성. 임계치 초과 시 「회백폐」 발현 (기침 → 호흡곤란 → 사망) |
| 물 반응 | 수분과 만나면 응고해 **「회니(灰泥)」** 회색 진흙이 된다 → 배수구·하수관 폐색 → 침수 이벤트 |
| 전기 영향 | 변전소 애자 표면 오염 → 섬락(閃絡) → **3일차 전후 단지 정전 확정** |
| 지속 | 강하는 8~14일, 이후 대기 중 부유 및 재비산이 20~40일 지속 |
| 원인 | **미상.** 게임 내내 밝혀지지 않는 것이 기본이며, 특정 조건에서만 단서가 열린다 |

### 3-2. 정부 발표가 세 번 바뀐다 (정보 신뢰의 붕괴)

| 시점 | 공식 발표 | 단톡방/라디오의 반응 |
|------|----------|---------------------|
| 1일차 | "해상 화물선 화학물질 유출로 추정. 실내 대피 권고" | "화물선이 저 넓이를 덮냐" |
| 4~6일차 | "해저 지각활동에 따른 화산성 분진으로 정정" | "화산이 있었단 얘긴 처음 듣는데" |
| 9~12일차 | "원인 조사 중. 추측성 정보 유포 자제 요청" | 음모론 3종 유행 시작 |

- 플레이어는 **어느 정보를 믿고 행동할지** 선택한다. 이 선택이 후반 엔딩 분기(이주/자립/비밀)의 씨앗이 된다.
- 발표 정정은 전원 사기 -5, 이웃 신뢰도 -3을 준다. **정보의 붕괴 자체가 자원 손실이다.**

### 3-3. 무대 — 새빛마을 3단지 103동

| 항목 | 설정 |
|------|------|
| 위치 | 서울 근교 위성도시. 1994년 준공, 재건축 조합 설립 인가 3년째 표류 |
| 규모 | 5개 동, 총 480세대. 103동은 12층 8라인 |
| 우리 집 | 103동 404호. 32평(전용 84㎡). 3베이 구조 (거실+안방+작은방 2) |
| 대피소 | 지하 3층 민방위 대피소. 면적 약 300㎡. 형광등 절반이 죽어 있음 |
| 대피소 현실 | 주민 개인 창고 12칸(자물쇠 있음), 자전거 20여 대, 폐가구, 재활용 분리수거장과 연결 |
| 관리사무소 | 지하 1층. 마스터키 보관함, 방송설비, 비상발전기(경유), 세대 도면 |
| 상가 | 단지 상가 1층에 편의점·약국·세탁소·치킨집. 지하 통로로 연결(막혀 있음) |
| 지리적 이점 | 지하 저수조(생활용수 40톤) — 회니 오염 위험 있지만 정수 트리의 핵심 |

> 재건축 표류 단지라는 설정은 두 가지를 준다: (1) 노후 설비로 인한 재해 이벤트의 개연성, (2) **찬성파/반대파로 이미 갈라진 주민 관계** = 신뢰도 시스템의 초기 조건.

## 4. 톤 & 테마

### 4-1. 톤 — "관리비 고지서가 오는 아포칼립스"

블랙코미디의 소재는 **거대한 재난 앞에서도 작동하는 한국 아파트의 일상 규범**이다.

| 웃긴 층 | 서늘한 층 (같은 소재의 뒤집기) |
|--------|------------------------------|
| 지하에서도 분리배출을 강요하는 이웃 | 그 이웃이 배급 장부를 관리하겠다고 나선다 |
| 단톡방에 올라오는 "확인했습니다 👍" 도배 | 단톡방 투표로 우리 가족의 배급이 깎인다 |
| 문틈으로 들어온 관리비 고지서 | 고지서 뒷면에 누군가 "404호 물 많음"이라고 적어 놨다 |
| 재건축 반대파 아저씨의 훈수 | 반대파/찬성파로 대피소가 두 편으로 갈린다 |
| 층간소음 항의 (지하 3층에서) | 위층 소리는 사람이 아니다 |
| 반상회 안건 상정 절차 준수 | 절차대로 우리 가족의 축출이 의결된다 |

### 4-2. 테마 3층

1. **표층: 트리아지** — 다 데려갈 수 없다. 무엇을/누구를 남길 것인가.
2. **중층: 공정성** — 나눠야 산다. 그런데 공정한 배급이란 무엇인가. 아이 우선? 노인 우선? 일하는 사람 우선?
3. **심층: 규범** — 재난은 규범을 시험한다. 우리는 절차를 지키며 서로를 버릴 수 있는 사람들이다.

### 4-3. 표현 수위 원칙
- 실존 국가·정당·기업·특정 지역을 지목하지 않는다. 재난 원인은 끝까지 미상으로 둔다.
- 사망·질병은 **텍스트와 실루엣**으로 처리. 고어 없음.
- 아동·노인 캐릭터의 사망은 가능하되, 연출은 일지 텍스트 1줄 + 정적 3초로 절제한다.
- 실제 재난 피해자를 연상시키는 특정 사건 재현은 하지 않는다.
- 등급 목표: **GRAC 12세 이용가 / ESRB Teen / PEGI 12**

## 5. 타깃 & 포지셔닝

### 5-1. 1차 타깃
| 세그먼트 | 규모 근거 | 유인 |
|---------|----------|------|
| 원작 *60 Seconds!* 한국 플레이어 | 스팀 한국어 리뷰 다수, 유튜브 실황 조회수 누적 수백만 | "그 게임의 한국판" 즉시 이해 |
| 국산 인디 시뮬레이션 소비층 | 로그라이크·경영 시뮬 국내 인디 팬층 | 회차 반복 + 도감 수집 구조 |
| 아파트 거주 생활 공감층 (25~45세) | 국내 주거의 절대다수 | 반상회·단톡방·관리비 유머의 즉각적 공감 |
| 실황 스트리머 | 짧은 회차, 시청자 투표 친화 (반상회 투표!) | ★ **반상회 투표를 시청자 투표로 대체**하는 스트리머 모드 |

### 5-2. 경쟁/유사작 포지셔닝

| 작품 | 강점 | 본작의 차별점 |
|------|------|-------------|
| 60 Seconds! | 수집 단계의 물리적 코미디 | 밀실 내 사회 시스템, 조리·환기 트레이드오프 |
| This War of Mine | 도덕적 무게, 밤 탐색 | 회차 20~40분의 경량 구조, 코미디 톤 |
| Frostpunk | 사회 규율 법령 시스템 | 규모를 도시→**밀실 12명**으로 축소해 얼굴 있는 갈등으로 |
| 60 Parsecs! | SF 확장 | 오히려 축소·밀착 방향. 우주가 아니라 **지하 3층** |

### 5-3. 포지셔닝 문장
> **"This War of Mine의 도덕적 무게를, 60 Seconds!의 25분 회차에, 한국 아파트 반상회의 얼굴로."**

### 5-4. 스트리머 모드 (마케팅 장치)
반상회 투표 안건이 발생하면 채팅 명령어로 시청자가 투표 → 결과가 게임에 반영.
- 회차당 3~7회 발생 → 시청자 참여 지점이 구조적으로 보장됨
- 시드 코드 공유 → "같은 집으로 도전" 챌린지
- 이것은 부가 기능이 아니라 **국내 인디 게임의 주 유입 채널(실황)에 맞춘 설계**다.

## 6. 플레이어 여정 (회차 기대 곡선)

| 회차 | 플레이어 상태 | 설계 의도 |
|------|-------------|----------|
| 1회차 | 120초에 아무것도 못 챙기고 3명 두고 내려옴. 6일차 사망 | 시간 압박 학습. **실패 자체를 엔딩으로 인정** ("빈손") |
| 2~4회차 | 식량/물은 챙기지만 도끼·약을 놓쳐 이벤트로 사망 | 게이팅 아이템 학습 |
| 5~10회차 | 물자는 되지만 이웃 신뢰도가 무너져 축출 | **공동체가 진짜 난관임을 학습** — 본작의 정체성 |
| 11~20회차 | 첫 구조 엔딩. "생존자 3명, 등급 C" | 등급 최적화 동기 발생 |
| 21~40회차 | 자립/이주 루트 도전, 이웃 조합 실험 | 빌드 다양성 소비 |
| 40회차+ | 비밀 엔딩 2종, 챌린지 시드, 하드코어 | 롱테일 |
