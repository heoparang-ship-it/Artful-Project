# 02. 1단계 — 120초 수집

## 1. 왜 60초가 아니라 120초인가

원작의 60초는 **평면 단독주택 + 문 앞 방공호 + 가족 4인**을 전제로 캘리브레이션된 값이다.
본작은 세 가지가 다르다.

| 변수 | 원작 | 본작 | 추가 소요 |
|------|------|------|----------|
| 대피소 동선 | 집 옆 (왕복 3~4초) | 4층 → 지하 3층 (왕복 12초) | **+8초/왕복** |
| 파티 규모 | 4인 | 5인 + 반려견 1 | 호출 3초 × 2명 = **+6초** |
| 설득 대상 | 없음 | 이웃 초인종 (선택) | **+5~10초/세대** |

3~4회 왕복을 기본 설계로 잡으면 왕복 손실만 36~48초. 원작과 동일한 "수집 실행 시간 40~45초"를 확보하려면 **총 120초**가 필요하다.

> **설계 결론:** 총 120초. 이 중 **왕복 이동에 약 40%가 강제로 소모**되도록 설계한다.
> 즉 본작의 수집 단계는 "얼마나 빨리 집는가"보다 **"몇 번 왕복할 계획을 세우는가"** 의 게임이다.

### 난이도별 시간
| 난이도 | 총 시간 | 표시 | 오차 |
|--------|--------|------|------|
| 민방위 훈련 (이지) | 150초 | 정확 표시 | 없음 |
| 실제 상황 (노멀) | 120초 | 정확 표시 | 없음 |
| 실제 상황입니다 (하드) | 105초 | 정확 표시 | 없음 |
| 오차 옵션 ON (하드코어) | 105초 표시 | 실제 90~120초 | ±15초 랜덤, 마지막 10초에만 실제 카운트 공개 |

## 2. 오프닝 시퀀스 (연출 스크립트)

```
[0:00~0:06] 검은 화면. 거실 TV 소리(예능 웃음소리). 벽시계 초침.
[0:06]      온 가족 스마트폰 4대가 동시에 진동. 위급재난문자 경보음(삐빅-).
[0:07~0:11] 화면 켜짐. 스마트폰 클로즈업.
              ┌───────────────────────────────────┐
              │ [행정안전부] 오후 4시 12분         │
              │ 서해 방면 유독성 강하분진 접근.   │
              │ 즉시 실내 또는 지하 대피시설로    │
              │ 이동하십시오. 도달 예상 약 2분.   │
              └───────────────────────────────────┘
[0:11~0:15] 창밖. 민방위 사이렌 상승음.
              단지 방송(잡음 섞인 노년 남성 목소리):
              "아, 아... 주민 여러분께 알려드립니다. 지금은... 지금은 실제 상황입니다."
[0:15]      ▶ 타이틀 『실제 상황입니다』
[0:16]      게임 시작. 카운트다운 120 시작.
```

- 오프닝은 **스킵 가능**하되 초회차는 강제 시청.
- 이후 회차부터는 [0:06] 진동 → [0:16] 즉시 시작 (3초 압축).

| 방 | 주요 스폰 | 특징 |
|----|----------|------|
| 주방/다용도실 | 라면 묶음, 즉석밥, 참치캔, 김치통, 생수 2L, 부탄가스, 부르스타, 정수 필터, 냄비 | ★ 최고 가치 밀집. 여기만 털어도 3왕복 |

| 안방 | 처방약(혈압/천식), 이민가방(캐리어), 현금, 예비군 방독면, 청테이프 | ★ **캐리어 = 슬롯 +4** 최우선 |
| 딸 방(고3) | 문제집, 노트북, 보조배터리, 이어폰, 화장품 | 사기 아이템 편중 |
| 아들 방 | 장난감, 만화책, 야구배트, 핫팩, 사료 | 무기(배트) 대체 획득처 |
| 욕실 | 마스크 박스, 수건, 상비약, 물통, 세제 | 물 확보 보조 |
| 베란다/세탁실 | 김장독, 생수 박스, 아이스박스, 삽, 등산버너, 우비 | ★ 물 대량 스폰. 동선 최장 |
| 현관/신발장 | 우산, 장갑, 등산화, 택배 상자(랜덤 내용물) | 나가는 길에 1칸 챙기기 |
| 4층 복도 소화함 | **소화기, 소화도끼** | ★ 무기 확정 스폰. 계단 옆 = 왕복 시 무료 획득 |

> "무기를 챙길까 아이를 챙길까"의 원작 딜레마를 **"복도로 나올 때 1칸을 비워둘 것인가"** 로 변주한다.

## 4. 운반 시스템

### 4-1. 슬롯

| 상태 | 슬롯 수 | 이동속도 |
|------|--------|---------|
| 기본 (양손) | 2 | 100% |
| + 이민가방(캐리어) 획득 | 2 + 4 = **6** | 85% (캐리어가 한 손 점유하지 않음, 끌고 감) |
| + 아이스박스 획득 | 2 + 3 = 5 | 80% (양손 중 1칸 점유) |
| + 배낭 획득 | 2 + 3 = 5 | 95% |
| 최대 중첩 | 양손 2 + 캐리어 4 + 배낭 3 = **9** | 78% |

- **부피 아이템**은 2칸을 차지한다: 생수 박스, 김장독, 부르스타, 공기청정기, 자동차 배터리, 정수기
- **사람**은 슬롯을 차지하지 않지만 조건이 붙는다 (4-3 참조)

### 4-2. 왕복 시간표

| 구간 | 소요 |
|------|------|
| 404호 현관 → 4층 복도 계단 앞 | 2초 |
| 계단 4층 → 지하 3층 (하강, 7개 층) | 5초 |
| 대피소 진입 + 물자 내려놓기 | 1초 |
| 지하 3층 → 4층 (상승) | 7초 |
| 4층 복도 → 404호 현관 | 2초 |
| **왕복 1회 합계** | **17초** |
| 짐 만재(78% 속도) 시 하강 | 6.5초 → 왕복 **18.5초** |
| 노인/아동 동행 시 | +30% → 왕복 최대 **23초** |

**120초 예산 배분 예시 (숙련 플레이)**
```
0~14초   집 안 이동 + 1왕복분 6칸 확보 (주방 집중)
14~31초  1차 하강 왕복 (17초)  ── 누적 31초
31~44초  안방 캐리어 + 처방약 + 청테이프 + 안방 가족 호출
44~63초  2차 하강 (할머니 동행, 19초) ── 누적 63초
63~76초  베란다 생수 박스 + 삽, 복도 소화도끼
76~95초  3차 하강 (19초) ── 누적 95초
95~112초 남은 가족 2명 호출 후 4차 하강 (17초) ── 누적 112초
112~120초 여유 8초 (사이렌 종료 전 대피소 문 폐쇄)
```
→ **4왕복 = 최대 성과.** 이것이 상한이며, 초회차 플레이어는 보통 2왕복에 실패한다.

### 4-3. 사람 데려가기

| 대상 | 호출 방식 | 비용 | 제약 |
|------|----------|------|------|
| 성인 (아내/남편) | 말 걸기 3초 | 없음 | 이후 자동 추종. **혼자 지하로 내려보낼 수 있음(+물자 2칸 운반)** |
| 고3 딸 | 말 걸기 4초 | 이어폰 착용 중이면 +2초 | 자동 추종. 문제집을 두고 가면 지하에서 사기 -10 |
| 초등 아들 | 손 잡기 (양손 슬롯 1 점유) | 슬롯 -1 | 손 놓으면 제자리 대기. 속도 -20% |
| 할머니 | 부축 (양손 슬롯 1 점유) | 슬롯 -1 | 속도 -30%. **혈압약 없이 데려가면 6일차부터 위기** |
| 반려견 또리 | 안기(슬롯 1) 또는 케이지(부피 2) | 슬롯 -1~2 | 안고 가면 도중에 뛰어내릴 확률 15% |

> **트리아지의 수학:** 5인 + 개를 전부 데려가려면 최소 3왕복이 사람 이동에 쓰인다.
> 그러면 물자는 6~8칸밖에 못 가져간다. 물자를 챙기면 사람이 남는다.
> **본작은 이 계산을 플레이어가 매 회차 다시 하도록 강제한다.**

### 4-4. 성인 단독 파견 (신규 메커니즘)
성인 가족(아내/남편, 이웃 성인)에게 물자를 들려 **먼저 내려보낼 수 있다.**
- 호출 3초 + 물자 인계 1초 → 성인이 2칸을 들고 자율 하강 (플레이어는 계속 집을 뒤짐)
- 즉 **인력을 물류에 투입하는 선택지**. 사람이 많을수록 물자를 더 가져갈 수 있다 → 이웃 구조의 인센티브
- 리스크: 파견한 성인은 도중 이벤트(넘어짐 8%, 다른 세대 사람과 실랑이 6%) 발생 가능

## 5. 이웃 초인종 (한국판 고유 요소)

4층 복도의 403호·405호, 그리고 계단을 내려가며 3층·2층 문을 두드릴 수 있다.

| 행동 | 시간 | 결과 |
|------|------|------|
| 초인종 1회 | 2초 | 응답 롤 판정 |
| 문 두드리며 소리치기 | 4초 | 응답 확률 +25% |
| 소화도끼로 문 파괴 | 8초 | 무응답 세대 강제 진입 → **물자 획득 가능 / 신뢰도 초기값 -20** |

**응답 결과표**
| 결과 | 확률 | 내용 |
|------|------|------|
| 즉시 합류 | 25% | 이웃 1~2명이 물자를 들고 따라온다 (물자 1~3칸 무료 획득) |
| 지연 합류 | 20% | "잠깐만요!" → 25초 후 자력으로 대피소 도착 |
| 거절 | 20% | "우린 집에 있을게요" → 이후 대피소 문 앞 이벤트로 재등장 |
| 무응답 | 25% | 없거나 못 들음. 도끼로 부술 수 있음 |
| 역요청 | 10% | "우리 애 좀 데려가 주세요" → 아이만 합류 (슬롯 1 점유) |

> ★ **이웃은 자원이면서 비용이다.** 1인당 하루 식량 1·물 1을 먹지만, 특성(마스터키·의료·오토바이)과 노동력(탐색·물류)을 준다.
> 그리고 신뢰도 시스템의 참여자가 된다. **몇 명을 데려가는가가 본작의 최대 빌드 결정이다.**

## 6. 이동 · 물리 · 실수

| 요소 | 규칙 |
|------|------|
| 걷기 / 뛰기 | 뛰기 = 속도 165%, 단 함정 오브젝트 충돌 확률 40% |
| 넘어짐 | 시간 손실 2.5초 + 들고 있던 아이템 중 1개 낙하(비파괴) + 유리류는 파괴 |
| 유리 파괴 아이템 | 생수 페트(누수 50%), 김치통(전량 손실), 소주병, 정수기 |
| 문 | 방문 열기 0.4초. 열어둔 문은 유지됨 → 동선 사전 개방이 유효 전략 |
| 시야 | 쿼터뷰. 벽은 하프컷으로 실내 가시화 |
| 마지막 10초 | 화면 채도 저하 + 창밖이 회백색으로 흐려짐 + 사이렌 피치 상승 |
| 시간 초과 | 지상에 남은 인원은 **「지상 잔류」** 상태로 소실. 5일차 문 앞 이벤트로 1회 재등장 가능(생존 확률 20%) |
| 플레이어 초과 | 주인공이 지상에 있으면 즉시 게임오버 엔딩 「404호」 |

## 7. 대피소 문 폐쇄 (단계 종료)

120초 종료 시점 또는 **자발적 조기 폐쇄** 중 선택.

| 폐쇄 시점 | 효과 |
|----------|------|
| 자발적 조기 폐쇄 (남은 시간 t) | 회백 초기 유입량 **-t/10** (최대 -12). 즉 **20초 남기고 닫으면 초기 오염 -2** |
| 120초 만료 시 자동 폐쇄 | 회백 초기 유입 기본값 |
| 폐쇄 후 지각 도착자 | 지연 합류 이웃은 문 앞 노크 → 열어줄지 선택 (열면 회백 +3, 신뢰 +10) |

> **마지막 결정:** 시간이 12초 남았고 딸이 아직 3층 계단에 있다. 문을 지금 닫으면 오염이 1 줄어든다.
> 이 3초의 선택이 원작 마지막 순간의 긴장을 한국식으로 번역한 지점이다.

## 8. 수집 단계 결산 화면

```
┌─────────── 대피 완료 ───────────┐
│  경과 시간         118초         │
│  왕복 횟수         3회           │
│  확보 물자         19점          │
│  대피 인원         4 / 5 (+개)   │
│  지상 잔류         김하늘(18)    │
│  초기 회백 농도    12 / 100      │
│  이웃 합류         2명 (403호)   │
├─────────────────────────────────┤
│  등급  B   (수집 점수 640점)     │
└─────────────────────────────────┘
```

- 수집 점수는 「60초만」 모드(수집 전용)의 리더보드 및 주간 챌린지에 사용
- 점수식: `(물자가치 합) + (대피인원 × 60) + (남은초 × 4) − (파괴손실 × 15)`
