# 03. 2단계 — 지하 3층 생존

## 1. 단계 전환 연출

문이 닫히면 소리가 먼저 바뀐다. 사이렌이 벽 두께만큼 뭉개지고, 남는 건 형광등 안정기의 웅웅거림과 물방울 소리.
플레이어는 이제 **1인칭 정지 화면 + 일지 UI**로 전환된다 (원작의 벙커 뷰 계승).

```
┌────────────────────────────────────────────────────────┐
│  103동 지하 3층 민방위 대피소            1일차 (수)   │
│  ┌──────────────────────────────────────────────────┐  │
│  │  [ 대피소 일러스트: 형광등 2개만 살아 있는 300㎡ ] │  │
│  │   · 좌측: 주민 창고 12칸 (자물쇠 8개)              │  │
│  │   · 중앙: 우리 가족 자리 (담요/짐)                 │  │
│  │   · 우측: 403호 가족 자리                          │  │
│  │   · 후면: 환기구 / 배수구 / 저수조 점검구          │  │
│  └──────────────────────────────────────────────────┘  │
│  식량 8   물 6   약 2   가스 3   전력 4   회백 12/100  │
├────────────────────────────────────────────────────────┤
│  ▣ 관리일지                                            │
│  「대피소 문을 닫았다. 형광등이 두 개만 살아 있다.     │
│   하늘이는... 못 데려왔다. 3층 계단에서 멈춰 있었다.」 │
├────────────────────────────────────────────────────────┤
│  [ 배급 ]  [ 정비 ]  [ 탐색 ]  [ 대화 ]  [ 일지 넘김 ]│
└────────────────────────────────────────────────────────┘
```

- 대피소 일러스트는 **누적 변화**한다: 정비 진행, 인원 증감, 오염도, 조명 상태가 그림에 반영된다.
- 관리일지의 서체는 아파트 관리사무소 업무일지의 볼펜 필기체.

## 2. 하루의 구조 (1일 = 1턴)

```
① 아침 갱신     상태 진행(굶주림/갈증/질병/사기), 회백 유입, 처방약 소모
② 배급 결정     인원별 정량/절식/금식 지정 (또는 반상회 규칙 자동 적용)
③ 행동 2액션    조리 · 정비 · 제작 · 탐색 파견 · 대화 · 창고 개방 · 단톡방 확인
④ 이벤트 1~2장  이벤트 덱에서 드로우 → 선택지 판정
⑤ 밤 기록       일지 텍스트 생성, 사기·신뢰도 정산, 다음날 예고 힌트
```

- 액션 수는 **성인 생존자 수에 따라 증감**: 성인 1명 = 1액션, 2명 = 2액션, 3명 이상 = 3액션 (상한 3)
- 즉 이웃을 데려오면 소비도 늘지만 **하루에 할 수 있는 일이 늘어난다.** 이 트레이드오프가 인원 관리의 핵심.

## 3. 자원 5종

| 자원 | 단위 정의 | 획득 | 소모 |
|------|----------|------|------|
| **식량** | 성인 1명 1일 정량 | 수집, 탐색, 콩나물 재배, 이웃 공유 | 배급, 이벤트 |
| **물** | 성인 1명 1일 정량 | 수집, 탐색, 저수조+정수, 결로 채집 | 배급, 조리, 세척, 치료 |
| **약** | 1회 투여분 | 수집, 약국 탐색, 이웃(약사) | 치료, **처방약 정기 소모** |
| **가스** | 부탄가스 1캔 (조리 3회분) | 수집, 상가/세대 탐색 | 조리, 난방, 살균 |
| **전력** | 소형 가전 1일 가동분 | 보조배터리, 자동차 배터리, 발전기, 자전거 발전 | 공기청정기, 조명, 스마트폰, 전기포트 |

### 3-1. 인원별 소모량

| 대상 | 식량/일 | 물/일 | 비고 |
|------|--------|-------|------|
| 성인 (18~64) | 1.0 | 1.0 | — |
| 아동 (9세) | 0.5 | 0.5 | 사기 하락 1.5배 |
| 노인 (72세) | 0.5 | 1.0 | **처방약 1 / 3일** |
| 유아·신생아 | 0.3 | 0.8 | **분유 1/일 + 기저귀 필요** (별도 자원) |
| 반려견 | 0.5 | 0.5 | 사료 없으면 사람 음식 소모, 사기 -1 추가 |

### 3-2. 배급 모드

| 모드 | 소모 배율 | 즉시 효과 | 누적 효과 |
|------|----------|----------|----------|
| 정량 | 1.0 | 사기 +3 | 없음 |
| 절식 | 0.5 | 사기 -5 | 3일 연속 → 「허약」 (탐색 성공률 -25%, 질병 저항 -30%) |
| 금식 | 0 | 사기 -15 | 즉시 「굶주림」 단계 +1 |
| 특별 배급 | 1.5 | 사기 +12 | 이벤트 보상 후 사기 회복용 |

**중요:** 배급은 **인원별로 다르게 줄 수 있다.** 그리고 그것이 신뢰도 시스템의 최대 입력값이다.
- 우리 가족 정량 / 이웃 절식 → **신뢰도 -12/일** (발각 확률 65%)
- 전원 균등 절식 → 신뢰도 유지
- 아픈 사람 정량 / 나머지 절식 → 신뢰도 +6/일

### 3-3. 굶주림 · 갈증 진행

| 단계 | 굶주림 (식량 0일 기준) | 갈증 (물 0일 기준) |
|------|----------------------|-------------------|
| 정상 | — | — |
| 1단계 「배고픔」 | 2일 | 1일 |
| 2단계 「허약」 | 4일 (탐색 불가) | 2일 (탐색 불가) |
| 3단계 「탈진」 | 6일 (액션 기여 불가) | 3일 |
| 사망 | 9일 | **5일** |

> 물이 식량보다 2배 빠르게 죽인다. 그런데 **라면은 물을 먹는다.** 이 비대칭이 조리 결정을 어렵게 만든다.

## 4. ★ 조리 · 열원 · 환기 (본작의 심장)

### 4-1. 조리 표

| 음식 | 식량 산출 | 물 소모 | 가스 소모 | 부가 |
|------|----------|--------|----------|------|
| 라면 (조리) | 2.0 | 1.0 | 0.33 | 사기 +8 (★온기) |
| 라면 (생라면) | 1.0 | 0 | 0 | **갈증 +1**, 사기 -2 |
| 즉석밥 (햇반) | 1.0 | 0.3 | 0.33 | 사기 +4 |
| 즉석밥 (생) | 0.5 | 0 | 0 | 사기 -4, 배탈 확률 15% |
| 참치캔/스팸 | 1.0 | 0 | 0 | 갈증 +0.5 (염분) |
| 김치 | 0.5 | 0 | 0 | **배탈/감염 저항 +20%**, 갈증 +0.5 |
| 콩나물국 | 1.5 | 1.0 | 0.33 | 사기 +6, 「허약」 회복 속도 2배 |
| 물 끓이기 (살균) | — | — | 0.33 | 오염수 2 → 안전한 물 2 |

> **온기 보너스:** 조리한 뜨거운 음식은 사기를 크게 회복한다. 원작의 "수프 통조림"에는 없던 축이다.
> 지하는 춥다. 뜨거운 라면 국물 한 그릇의 가치가 시스템으로 표현되어야 한다.

### 4-2. 산소 · 환기

밀폐된 300㎡ 지하에서 부르스타를 켜면 산소가 준다.

| 상태 | 규칙 |
|------|------|
| 산소 게이지 | 0~100. 시작 100 |
| 인원 호흡 | -1 / 인원 / 일 |
| 조리 1회 | **-6** |
| 난방(가스히터) 1회 | -10 |
| 촛불/양초 조명 | -2 / 일 |
| 산소 70 이하 | 전원 사기 -3/일, 두통 → 발열 확률 +10% |
| 산소 50 이하 | 전원 「저산소」: 액션 1 감소, 사망 확률 발생 |
| 산소 30 이하 | 1일 후 최약체 1명 사망 |

**환기 (유일한 회복 수단)**

| 환기 방식 | 산소 회복 | 회백 유입 | 조건 |
|----------|----------|----------|------|
| 환기구 완전 개방 | +40 | **+6** | 없음 |
| 환기구 부분 개방 | +20 | +3 | 없음 |
| 필터 환기 (마스크 필터 개조) | +35 | **+1** | 제작 필요 (KF94 2 + 청테이프 1) |
| 정화 환기 (공기청정기 병행) | +40 | **0** | 전력 1 + 필터 1 |

> **이것이 본작의 대표 딜레마다.**
> 뜨거운 라면을 먹이려면 → 가스를 켠다 → 산소가 준다 → 환기해야 한다 → 회백이 들어온다 → 폐가 상한다.
> **"오늘 가족에게 따뜻한 밥을 먹일 것인가, 아니면 폐를 아낄 것인가."**

### 4-3. 회백 노출 (원작 방사능병의 한국적 번역)

| 항목 | 규칙 |
|------|------|
| 대피소 오염도 | 0~100. 수집 단계 결과로 초기값 8~20 |
| 기본 유입 | 밀폐 안 함 **+3/일** / 청테이프 밀폐 **+0.5/일** / 완전 밀폐(테이프+실리콘) **0** |
| 개인 노출도 | 오염도 ÷ 10 씩 매일 누적 (아동·노인은 1.4배) |
| 탐색 시 노출 | 방독면 **+0** / KF94 **+8** / 천마스크 +15 / 무보호 **+25** |
| 오염 물자 반입 | 세척(물 0.5) 안 하면 오염도 +2 |
| 「회백폐」 발현 | 개인 노출도 60 초과 시. 기침 → 3일 후 호흡곤란 → 8일 후 사망 |
| 치료 | 흡입기/스테로이드(약 2) → 진행 정지. 산소캔 → 1단계 회복. **완치 없음** |
| 공기청정기 | 전력 1 + 필터 소모(5일당 1) → 오염도 **-6/일** |

## 5. 상태이상 전체 목록

### 5-1. 신체

| 상태 | 발생 | 증상 | 치료 |
|------|------|------|------|
| 부상 | 이벤트, 탐색, 넘어짐 | 액션 기여 불가, 3일 후 「감염」 확률 40% | 구급상자 1 (간호조무사 있으면 성공률 +30%) |
| 감염 | 부상 방치, 오염수 섭취 | 발열 동반, 6일 후 사망 | 항생제 1 (약국 탐색), 없으면 소주 소독으로 지연 |
| 발열 | 감염, 저산소, 아동 | 배급 요구 1.5배, 사기 -5/일 | 해열제 1, 물 1, 3일 휴식 |
| 배탈/장염 | 상한 음식, 오염수, 생 즉석밥 | 물 소모 2배, 2일간 액션 불가 | 지사제 1, 김치 섭취 시 확률 감소 |
| 회백폐 | 노출도 60+ | 5-1 참조 | 진행 정지만 가능 |
| 만성질환 악화 | 처방약 3일 결손 | 노인 즉시 「위기」, 5일 후 사망 | 처방약 확보 (약국/세대 탐색) |
| 저산소 | 산소 50 이하 | 4-2 참조 | 환기 |
| 저체온 | 난방 3일 미실시 + 담요 부족 | 사기 -6/일, 발열 확률 +20% | 담요, 핫팩, 난방, 밀착 취침 |

### 5-2. 정신 (사기 시스템)

개인별 사기 0~100. 시작 60.

| 변동 요인 | 값 |
|----------|-----|
| 정량 배급 | +3 / 일 |
| 절식 | -5 / 일 |
| 금식 | -15 / 일 |
| 뜨거운 조리 음식 | +8 |
| 믹스커피 | +5 (1일 1회) |
| 소주 | +12, 다음날 -6, 갈증 +1 |
| 오락 (화투·부루마불·만화책·라디오 음악) | +8 (같은 오락 반복 시 -2씩 체감) |
| 가족앨범 | +10 (2일에 1회) |
| 반려견 존재 | +2 / 일 (전원) |
| 어둠 (조명 없음) | -3 / 일 |
| 외부 소식 없음 3일 연속 | -2 / 일 누적 |
| 좋은 소식 (라디오 구조 계획) | +15 (전원) |
| 정부 발표 정정 | -5 (전원) |
| 동료 사망 | -30 (가족) / -12 (이웃) |
| 이웃과 다툼 | -8 |

| 사기 구간 | 상태 |
|----------|------|
| 70~100 | 「든든함」 — 액션 성공률 +10% |
| 40~69 | 보통 |
| 20~39 | **「불안」** — 이벤트 선택지 1개 봉인, 밤에 잠 못 자는 이벤트 |
| 1~19 | **「공황」** — 자기 판단으로 행동: 물자 은닉 / 무단 외출 / 폭력 / 문 개방 |
| 0 | 「이탈」 — 밤중에 혼자 나가 사라짐 (5일 후 20% 확률로 귀환) |

> 원작의 「광기(insanity)」를 **불안 → 공황 → 이탈** 3단계로 세분하고, 각 단계가 **다른 종류의 사고**를 일으키게 했다.
> 특히 「공황」 상태의 이웃이 밤중에 대피소 문을 여는 이벤트는 본작 최악의 재앙 중 하나다.

|------|------|------|------|
| 해충 (바퀴/쥐) | 음식 노출 3일, 청소 미실시 | 식량 -1/일, 감염 확률 +15% | 살충제, 쥐덫, 고양이(이웃), 밀폐 보관 |

## 6. 정비 · 제작 트리 (후반 역전 시스템)

원작의 후반이 "감소하는 자원 소화"라면, 본작은 **생산으로 역전 가능**해야 한다.

### 6-1. 밀폐 · 방호 라인
| 항목 | 재료 | 효과 |
|------|------|------|
| 문틈 밀폐 | 청테이프 1 | 회백 유입 3 → 0.5 |
| 완전 밀폐 | 청테이프 2 + 실리콘 1 | 회백 유입 0 |
| 필터 환기구 | KF94 2 + 청테이프 1 | 환기 시 회백 +6 → +1 |
| 간이 음압실 | 비닐 2 + 테이프 2 + 팬 | 탐색 귀환자 격리 → 반입 오염 0 |

### 6-2. 물 라인 ★
| 항목 | 재료 | 효과 |
|------|------|------|
| 저수조 배관 개통 | 공구 1 + 호스 1 | **오염수 3/일 획득** (생활용수 40톤) |
| 간이 정수기 | 정수 필터 1 + 냄비 1 + 숯 1 | 오염수 2 → 안전한 물 2 (1일 1회) |
| 끓이기 | 가스 0.33 | 오염수 2 → 안전한 물 2 |
| 결로 채집 | 비닐 1 + 그릇 2 | 물 +0.5/일 (지하 습도 활용) |
| → 완성 시 | | **물 순수입 +2~3/일 → 물 문제 해소** |

### 6-3. 식량 라인 ★ 콩나물
> **지하는 어둡다. 콩나물은 어두울 때 잘 자란다.**
> 이 사실 하나가 본작 후반의 희망이자, 가장 한국적인 시스템이다.

| 항목 | 재료 | 효과 |
|------|------|------|
| 콩나물 시루 | 콩 1봉 + 시루/양동이 1 + 천 1 | 물 1/일 투입 → **4일 후 식량 3 산출**, 이후 6일 주기 재수확 |
| 시루 증설 | 양동이 1 추가 | 병렬 재배 (물 소모도 병렬) |
| 김장독 숙성 | 김장독 1 + 김치 | 김치 부패 방지 + 3일마다 식량 +0.5 |
| 새싹 재배 | 씨앗 1 + 물 | 6일 후 식량 1.5 |
| 버섯 배지 | 폐목재 + 종균 (희귀) | 8일 후 식량 4 |
| → 완성 시 | | **식량 순수입 +0.75/일 → 4인 절식 유지 가능** |

### 6-4. 전력 라인
| 항목 | 재료 | 효과 |
|------|------|------|
| 자전거 발전기 | 자전거 1(대피소 선점 물자) + 자동차 배터리 1 + 공구 1 | 액션 1 투입 → 전력 +2 |
| 비상발전기 가동 | 관리사무소 접근 + 경유 1 | 전력 +5 / 경유 1 |
| 태양광 보조배터리 | 탐색 획득 | 전력 +0.5/일 (회백으로 효율 40%) |

### 6-5. 정비 트리 완성 = 「자립」 엔딩 경로
```
밀폐 완료 + 물 순수입 ≥ 인원수 + 식량 순수입 ≥ 인원수×0.5 + 전력 ≥ 1/일
  → 21일차 이후 「자립」 엔딩 계열 해금
```

## 7. 대피소 선점 물자 (한국판 고유)

대피소는 주민 창고로 쓰이고 있었다. **시작 시 이미 무언가가 있다.**

| 항목 | 규칙 |
|------|------|
| 공용 잡동사니 | 항상 존재: 자전거 3~6대, 폐가구, 깨진 형광등, 유모차, 화분, 신문 묶음 |
| 개인 창고 12칸 | 8칸은 **자물쇠**. 4칸은 열려 있음 |
| 열린 창고 롤 | 각 칸당 아이템 1~3개 랜덤 (캠핑용품/제사용품/생수/공구/오래된 라면) |
| 자물쇠 개방 | ① 소화도끼(액션 1, **신뢰도 -8**) ② 마스터키(경비원 이웃) ③ 반상회 의결(합법, 신뢰도 +2) |
| 도덕 장치 | 창고 주인이 이웃으로 합류해 있으면 무단 개방 시 **신뢰도 -25 + 즉시 다툼 이벤트** |

> 자물쇠는 훌륭한 도덕 시험대다. 안에 뭐가 있는지 모른다. 열려면 남의 것을 부숴야 한다.
> 그리고 그 주인이 옆에 앉아 있을 수도 있다.

## 8. 종료 시점 (구조 타이밍)

플레이어는 **언제 끝나는지 모른다.** 이것이 배급 도박의 근원이다.

| 조건 | 최단 구조일 |
|------|-----------|
| 라디오 미보유 (신호 없음) | **35~45일차** (실질 클리어 불가) |
| 라디오 청취만 | 28~34일차 |
| 라디오 + 구조 신호 응답 (1회) | 21~27일차 |
| 라디오 + 신호 응답 + 좌표 송신 (관리사무소 방송설비) | **15~19일차** |
| 단톡방으로 구조대 일정 확인 | 예상 범위가 ±3일로 좁혀 표시됨 (배급 계획 가능!) |

> **정보가 곧 자원이다.** 라디오와 스마트폰 배터리에 자원을 투자하면 **"며칠 뒤에 끝난다"는 예측**을 얻고,
> 그 예측으로 배급을 정밀하게 짤 수 있다. 정보 투자가 식량 투자와 등가가 되도록 설계했다.
