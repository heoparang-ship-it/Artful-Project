# 08. 엔딩 (16종)

## 1. 엔딩 설계 원칙

1. **실패도 엔딩이다.** 원작처럼 실패 엔딩에 이름과 도감 항목을 준다. 실패가 수집 대상이 되면 재도전이 즐겁다.
2. **엔딩은 "누가 살았는가"가 아니라 "어떻게 살았는가"로 갈린다.** 같은 4명 생존이라도 신뢰도 90과 신뢰도 15는 다른 엔딩이다.
3. **한 문장으로 요약되는 이름을 붙인다.** 「의결」, 「빈 손」, 「우리 단지」 — 플레이어가 친구에게 말할 수 있어야 한다.
4. **에필로그는 짧게, 구체적으로.** 생존자별 후일담 1~2문장. 사망자는 이름과 일차만.

---

## 2. 엔딩 조건 판정 순서

```
매일 밤 ⑤단계에서 아래 순서로 검사한다.

1. 즉시 게임오버 검사
   주인공 사망 / 전원 사망 / 축출 가결 / 문 파괴(무기 없음)
2. 자립 조건 검사 (21일차 이상)
   밀폐 완료 + 물 순수입 ≥ 인원 + 식량 순수입 ≥ 인원×0.5 + 전력 ≥ 1/일
3. 이주 조건 검사 (16일차 이상)
   지도 보유 + 안전구역 좌표 확보 + 이동 가능 인원 ≥ 2 + 방호 장비
4. 구조 도래 검사
   구조일 도달 (정보 투자량에 따라 15~45일차)
5. 비밀 조건 검사
   특수 플래그 3종 이상 충족
```

- 2·3·5가 동시에 충족되면 **플레이어가 선택**한다 (마지막 결정 화면).

## 3. 구조 계열 (4종)

### E01 「명단 12번」 — 표준 구조
| 항목 | 내용 |
|------|------|
| 조건 | 구조일 도달 + 주인공 생존 |
| 등급 | 생존자 수·상태·신뢰도로 D~S |
| 에필로그 | 군용 트럭이 지하 3층 입구까지 들어온다. 명단을 부르는데 우리 동은 12번째였다. 이송 버스에서 처음으로 창밖을 본다. 회백은 아직 걷히지 않았다. |
| 후일담 | 생존자별 3개월 후 근황 1문장. 회백폐 환자는 "요양병원에 있다" |

### E02 「같이 나갔습니다」 — 고신뢰 구조
| 항목 | 내용 |
|------|------|
| 조건 | 구조일 도달 + 신뢰도 85+ + 이웃 3명 이상 생존 |
| 등급 | 최소 A |
| 에필로그 | 구조대가 "가족 단위로 탑승"이라고 했다. 아무도 움직이지 않았다. 결국 우리는 열두 명이 한 차에 탔다. 강태식씨가 마지막까지 자리를 안 옮겼다. |
| 특전 | 「단지 도감」 진행 +2, 시작 이웃 지명 해금 |

### E03 「홀로」 — 단독 구조
| 항목 | 내용 |
|------|------|
| 조건 | 구조일 도달 + 주인공만 생존 |
| 등급 | 최대 D |
| 에필로그 | 구조대원이 "몇 명이십니까"라고 물었다. 대답하는 데 시간이 걸렸다. 일지는 21권까지 썼다. 아무도 읽지 않을 것이다. |

### E04 「인계」 — 정부 조사팀 경유
| 항목 | 내용 |
|------|------|
| 조건 | 「정부 조사팀」 협조 + 회백폐 환자 격리 수락 + 구조일 도달 |
| 등급 | B 고정 |
| 에필로그 | 협조한 대가로 우선 이송됐다. 격리동으로 간 사람은 아직 소식이 없다. 서류에는 「양호」라고 적혀 있었다. |

## 4. 자립 계열 (3종)

|------|------|

| 등급 | **S 고정** |
| 에필로그 | 반상회 제9차 회의록. 안건 1호 「콩나물 배분」 가결. 안건 2호 「102동 생존자 수용」 가결. 안건 3호 「관리비 정산 연기」 가결. 우리는 아직 절차대로 살고 있다. |

### E07 「돌잔치」 — 특수 자립
| 항목 | 내용 |
|------|------|
| 조건 | 신생아 이웃 가족 전원 생존 + 30일차 도달 + 분유·기저귀 결손 0일 |
| 등급 | A 고정 |
| 에필로그 | 아기가 백일을 지하에서 넘겼다. 상은 라면 스프로 끓인 국 하나, 초코파이 하나. 사진을 찍을 폰은 배터리가 없었다. 그래서 다들 그 장면을 외웠다. |

## 5. 이주 계열 (3종)

### E08 「좌표」 — 안전구역 도달
| 항목 | 내용 |
|------|------|
| 조건 | 16일차+ / 시내 지도 + 해적방송 좌표 / 방호 장비 인원분 / 이동 가능 인원 2+ |
| 판정 | 이동 성공률 = 45% + 장비 + 인원 상태 보정 |
| 등급 | 성공 시 A / 부분 성공(일부 낙오) 시 C |
| 에필로그 | 좌표는 진짜였다. 폐교 체육관에 300명이 있었다. 급식 줄을 서면서 하늘이가 물었다. "여기서 수능 봐요?" |

### E09 「빈 좌표」 — 이주 실패
| 항목 | 내용 |
|------|------|
| 조건 | 이주 시도 + 좌표가 허위 정보였음 |
| 등급 | D |
| 에필로그 | 좌표에는 아무것도 없었다. 주차장 표지판만 남아 있었다. 돌아갈 길은 이미 회니로 덮여 있었다. |

### E10 「102동」 — 통합 이주
| 항목 | 내용 |
|------|------|
| 조건 | 옆 동 탐색 성공 + 교섭 성공 + 신뢰도 70+ |
| 등급 | B |
| 에필로그 | 102동 지하는 우리보다 넓고, 우리보다 사람이 많고, 우리보다 규칙이 많았다. 우리는 손님이 됐다. 손님에게도 당번표는 왔다. |

## 6. 붕괴 계열 (4종) — 실패 엔딩

### E11 「빈 손」 — 무기 없이 침입
| 조건 | 「셔터 소리」·「약탈 무리」에서 무기 미보유 |
|------|------|
| 에필로그 | 문이 열렸을 때 손에 든 것이 아무것도 없었다. 소화함은 4층 복도에 있었다. 계단으로 두 층 올라가면 있었다. |
| 설계 의도 | 원작의 "도끼 없으면 게임오버"를 계승. **위치를 알려주는 마지막 문장**으로 다음 회차를 학습시킨다 |

### E12 「의결」 — 축출 ★ 본작 고유
| 조건 | 신뢰도 9 이하 + 축출 안건 가결 |
|------|------|
| 에필로그 | 반상회 회의록 제7호. 안건 「404호 축출의 건」. 찬성 5, 반대 1, 기권 0. 가결. 서류에는 우리 이름이 정확히 적혀 있었다. 절차상 문제는 없었다. |
| 설계 의도 | **본작을 대표하는 실패.** 굶어 죽는 것보다 무섭다. 초회 10회차 내 실패 원인의 30~40%를 목표 |

### E13 「기록」 — 전원 사망
| 조건 | 전원 사망 |
|------|------|
| 에필로그 | 일지의 마지막 장. 글씨가 중간에 끊겨 있다. 3개월 뒤 정리 작업 중 발견됐다. 관리사무소 업무일지 양식이었다. |
| 특전 | 도감에 그 회차의 사망 원인 통계 기록 |

### E14 「털린 날」 — 약탈

|------|------|
| 에필로그 | 그들은 오래 있지 않았다. 필요한 것만 가져갔다. 필요한 것은 전부였다. |

## 7. 비밀 계열 (2종)

### E15 「1001호」 — 정체 ★
| 항목 | 내용 |
|------|------|
| 조건 | ① 「확인했습니다」 이벤트에서 3회 이상 개별 채팅 시도 ② 해적방송 3일 연속 청취 ③ 관리사무소 방송설비 확보 ④ 25일차 도달 |
| 등급 | 등급 없음 (별도 표기) |
| 내용 | 단톡방의 「1001호」는 6일차에 이미 사망했다. 그 폰은 지금 다른 사람이 쓰고 있다. 방송설비로 송신하면 그 사람이 응답한다. |
| 에필로그 | 회백의 원인에 대한 **첫 번째 실제 단서**. 정부 발표 3개가 모두 틀렸다는 것만 확인된다. 무엇이 맞는지는 알려주지 않는다. |
| 설계 의도 | 세계관의 진상을 **끝까지 주지 않는 것**이 본작의 원칙. 대신 "발표가 전부 틀렸다"는 사실만 확정해 준다 |

| 항목 | 내용 |
|------|------|
| 조건 | E15 달성 + 「우리 단지」(E06) 조건 동시 충족 + 하드 난이도 이상 |
| 등급 | **S+** |
| 에필로그 | 마지막 화면에서 오프닝이 다시 재생된다. 단, 이번엔 재난문자 발신 시각이 다르다. 우리가 문자를 받은 시각보다 **41분 앞서** 누군가는 이미 알고 있었다. 타이틀 자막이 바뀐다: 『실제 상황이었습니다』 |
| 특전 | 「41분」 실적, 뉴게임+ (오프닝 41분 전 시점에서 시작 — 수집 시간 무제한, 단 아무도 대피령을 믿지 않는다) |

## 8. 등급 산정

```
점수 = 생존자 점수 + 상태 점수 + 신뢰 점수 + 효율 점수 − 감점

생존자 점수:  가족 1인 120 / 이웃 1인 70 / 반려견 60
상태 점수:    건강 +40 / 허약 +10 / 회백폐 −30 / 부상 −10  (인원별)
신뢰 점수:    신뢰도 × 2  (이웃 0명이면 0)
효율 점수:    (남은 자원 총량 × 3) + (정비 라인 완성 수 × 60)
감점:         사망자 1인당 −100 / 아동 사망 −180 / 축출 시도 발생 −80
              은닉 발각 −50 / 반려견 유기 −70
```

| 등급 | 점수 | 표기 |
|------|------|------|
| S+ | 1400+ | 실제 상황이었습니다 |
| S | 1100~1399 | 우리 단지 |
| A | 850~1099 | 다 데리고 나왔습니다 |
| B | 600~849 | 살아남았습니다 |
| C | 380~599 | 몇 명은 |
| D | 150~379 | 겨우 |
| F | ~149 | 기록만 남았습니다 |

- **아동 사망 시 등급 상한 C** (감점만으로는 부족하다고 판단 — 서사적 무게를 시스템에 반영)
- **반려견 유기 시 등급 상한 B**

## 9. 엔딩 도감

```
┌──────────── 엔딩 도감  8 / 16 ────────────┐
│ 구조   ■ 명단 12번    □ 같이 나갔습니다   │
│        ■ 홀로         □ 인계              │
│ 자립   □ 지하 3층…    □ 우리 단지         │
│        □ 돌잔치                            │
│ 이주   ■ 좌표         ■ 빈 좌표           │
│        □ 102동                             │
│ 붕괴   ■ 빈 손        ■ 의결              │
│        ■ 기록         □ 털린 날           │
│ 비밀   □ ??????       □ ??????            │
├───────────────────────────────────────────┤
│ 최고 등급   A  (좌표 / 17일차 / 5명)      │
│ 최다 사인   갈증 (4회)                    │
│ 최다 실패   의결 (3회)   ← 신뢰도를 보세요│
└───────────────────────────────────────────┘
```

- 도감은 **실패 원인 통계**를 보여 준다. "최다 실패: 의결 3회"는 플레이어에게 무엇을 배워야 하는지 직접 말해 준다.
- 미해금 엔딩은 조건을 1/3만 공개 (예: 「우리 단지」 → "이웃과 함께 …")
