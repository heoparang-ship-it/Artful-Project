# 07. 이벤트 덱 (52종)

## 1. 드로우 규칙

```
매일 ④단계에서 이벤트를 드로우한다.

드로우 수:  1~7일차   → 1장
            8~20일차  → 1장 + (50% 확률로 2장)
            21일차+   → 2장

덱 구성:    일상(10) · 침입/외부(8) · 재해·설비(8) · 사회·공동체(10)
            정보(6) · 특수·서사(6) · 코미디(4)

가중치 =  기본가중치
        × 일차 게이트 (해당 일차 범위 밖이면 0)
        × 상태 트리거 보정 (해충 3일 미청소 → 「바퀴」 가중 ×6)
        × 중복 방지 (같은 회차에 뽑힌 카드는 ×0.15)
        × 인원 조건 (이웃 0명이면 사회 카드 대부분 0)
```

- **원작 계승 원칙:** 선택지의 정답은 숨긴다. 단 **아이템 보유·특성 보유 시 선택지가 추가**되고, 추가된 선택지는 대체로 유리하다.
- **위험 신호:** 또리(반려견)의 「경계」 특성이 있으면 침입 계열 카드를 1일 전에 예고한다.

| 51 | 「층간소음」 | 9~30 | 이웃이 우리 자리 쪽을 보며 "발소리 좀…" 한다. **지하 3층이다** | ① 사과(신뢰 +4, 이후 오락 사기 -3) ② "여기 지하인데요"(신뢰 -8, 사기 +8, 최고의 일지 한 줄) ③ 반상회 안건 8번 상정 |
| 52 | 「확인했습니다」 | 3~12 | 단톡방에 「확인했습니다 👍」가 열두 번 올라왔다 | ① 나도 올린다(신뢰 +2) ② 읽고 넘긴다 ③ **"몇 번 보내시는 거예요?"(신뢰 -5, 사기 +6)** |

## 9. 이벤트 설계 원칙

### 9-1. 게이팅 아이템 대응표
| 이벤트 | 필요 아이템 | 없을 때 |
|--------|-----------|--------|
| 「셔터 소리」·「약탈 무리」 | 무기 (소화도끼/배트/소화기) | **게임오버** |
| 「화재」 | 소화기 | 물자 -20%, 부상 2명, 산소 -30 |
| 「회니 역류」 | 삽 또는 비닐+테이프 | 3일 후 「침수」 확정 |
| 「바퀴」·「쥐」 | 살충제·쥐덫 | 식량 지속 손실, 전력 시설 정지 |
| 「배탈」·「발열」 | 상비약 | 물 소모 2배, 액션 상실 |
| 「구조대입니다」 | 정보 2채널 | 70% 확률로 물자 40% 강탈 |
| 할머니 「위기」 | 혈압약 | 5일 후 사망 |

> 원작이 "도끼 없으면 죽는다"는 단일 게이트로 학습을 유도했다면,
> 본작은 **7개의 게이트**를 두고 각각 다른 재난 축에 배치했다.
> 1회차에 전부 챙길 수 없으므로, 회차마다 "이번엔 무엇을 포기할까"가 달라진다.

### 9-2. 정답 은닉 vs 학습 가능성
| 원칙 | 구현 |
|------|------|
| 첫 조우는 정보 없이 | 처음 뽑힌 카드는 결과 확률 미표시 |
| 두 번째부터 힌트 | 도감에 「이전 결과」 기록 → 선택지에 회색 주석 표시 |
| 특성/아이템은 확정 정답 제공 | 할머니 「피난 경험」, 딸 「정보 판별」, 수첩 등 |
| 도감 완성 후 | 확률 수치 완전 공개 (숙련 플레이어의 최적화 놀이 지원) |

### 9-3. 일차별 이벤트 압력 곡선

```
압력
 ▲
 │                                     ┌────  약탈·축출·회백폐
 │                          ┌──────────┘
 │              ┌───────────┘  침수·해충·사회갈등
 │      ┌───────┘  정전·배탈·문 두드림
 │──────┘  일상·잠자리·형광등
 └──┬────┬────┬────┬────┬────┬────┬────▶ 일차
    1    5    10   15   20   25   30
         ↑정전      ↑기지국    ↑최단구조   ↑표준구조
```

- 1~5일차: **학습 구간**. 게이팅 이벤트 없음. 자원 감소를 체감시킨다.
- 6~12일차: **압박 구간**. 정전·해충·회니. 탐색을 강제한다.
- 13~20일차: **사회 구간**. 신뢰도가 무너지기 시작. 본작 고유 난관.
- 21일차+: **파멸 구간**. 약탈·회백폐 발현·축출. 여기까지 온 플레이어는 이미 무언가 잃었다.
